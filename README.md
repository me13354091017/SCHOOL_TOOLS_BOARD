# 墨板 InkBoard

面向**课堂触控一体机**的开源白板软件。纯原生 Web（Canvas 2D）实现，**零运行时依赖、单文件可离线、不装环境**，打开浏览器就能上课。

> 血缘：核心笔迹工程思路源于作者上一个项目 [SCHOOL_TOOLS_PDF](https://github.com/me13354091017/SCHOOL_TOOLS_PDF)（WPF / .NET 10 / InkCanvasForPDF 派生的 PDF 墨迹白板）。本项目把那套「**时间笔锋 + 手绘转标准图形 + 函数/坐标系图形**」的墨迹经验搬到浏览器，几何算法全部自研重写，以适配一体机的手写笔与触摸。

## 在线试用

- 在线版： https://me13354091017.github.io/SCHOOL_TOOLS_BOARD/
- 离线单文件版：`dist/inkboard-standalone.html`（约 165 KB，双击即用，断网也能上课；由 CI 自动生成）

## 为什么是 Web，而不是继续用 WPF

| 维度 | WPF（上游项目） | 墨板 InkBoard |
|---|---|---|
| 部署 | 需安装 .exe、.NET 运行时、驱动 | 打开浏览器即可，可 PWA 离线 |
| 平台 | Windows only | Windows / 鸿蒙 / Android 一体机通吃 |
| 分发 | Inno Setup 安装包 | GitHub Pages / U 盘拷一个 HTML |
| 升级 | 重新安装 | 刷新页面 |
| 手写笔 | 需 WinRT 墨水栈 | Pointer Events + coalesced 事件，直取高频采样 |

一体机的痛点不是“功能少”，而是“装不上、跑不动、一升级就崩”。所以本项目把“有没有”交给浏览器，把“卡不卡”交给分层画布与脏区重绘。

## 核心能力

### 书写
- **时间笔锋**（向希沃系笔迹学习）：抬笔前笔尖继续缓慢生长至目标粗细，抬笔即停，自然形成锋颖；宽度同时受速度与压感调制。
- 双层画布：`#layer-page` 静态层（增量重绘）+ `#layer-live` 动态层（实时笔迹），抬笔才落层。
- 4px 重采样 + 中心线平滑 + 法线轮廓 + 急转角收窄，`Path2D` 二次曲线填充，60 FPS 下笔迹不断尾。
- 荧光笔：等宽平涂，`alpha 0.34`，可叠色。
- 手掌防误触：刚抬笔 600ms 内的触摸点忽略。

### 图形与数学
- 8 种图形：直线 / 箭头 / 矩形 / 圆 / 三角形 / 多边形 / 平面直角坐标系 / 函数图像。
- **手绘自动转标准图形**：直线度 > 0.86 → 直线；闭合笔画按 RDP 顶点数分类（3 → 三角形、4 → 矩形、圆度 CV < 0.16 → 圆、5~8 → 多边形）。
- **自研表达式解析器**（不用 `eval`）：`sin cos tan sqrt abs log ln exp floor ceil round sign`、`^`、`pi e x`。
- 坐标系与函数图像共用「bbox 内 ±5 单位、unit = min(w,h)/10」的换算，两者天然对齐。

### 页面与板书
- 多页板书 + 左侧缩略图栏（新建 / 复制 / 删除 / 换背景）。
- 5 种背景：纯白、方格、点阵、横线、黑板。
- 页面比例 16:9 / 4:3 一键切，内容自动等比缩放不跑出页面。
- 撤销 / 重做 80 步，自动保存到 IndexedDB（关掉再开还在）。

### 课堂工具（9 项）
计时器（圆环进度 + 到点提示音）· 随机点名（名单本地保存）· 聚光灯（跟随指针、滚轮改光斑）· 遮罩揭幕（下拉拉手逐层露出）· 放大镜（双层合采、真 1.9×）· 板中板（草稿贴回白板）· 导入 PDF（最多 200 页，每页转白板页）· 页面背景 · 快捷键说明。

### 导出
单页 PNG · 全部页面 PNG · 打印 / PDF · `.inkboard` 工程文件（JSON）· 单页 SVG 矢量。

### 大屏适配
`--u` CSS 变量由视口自动计算（1920×1080 = 1，4K = 2），全部 UI 尺寸、间距、圆角、字号跟着缩放；DPR 面积超过 2.6M 像素时自动降到 1.25 封顶。右上角性能面板可实时看 FPS。

## 快捷键

| 键 | 功能 | 键 | 功能 |
|---|---|---|---|
| `P` | 钢笔 | `M` | 荧光笔 |
| `E` | 橡皮 | `S` | 图形 |
| `T` | 文本 | `V` | 选择 |
| `L` | 激光笔 | `H` | 漫游 |
| `空格`（按住） | 临时漫游 | `双指` | 缩放 / 平移 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 | `Ctrl+D` | 复制选中 |
| `Ctrl+A` | 全选 | `Del` | 删除选中 |
| `Ctrl+S` | 导出工程文件 | `←` `→` | 翻页 |
| `F` | 全屏授课 | `Esc` | 收回工具 / 关弹窗 |

## 构建与本地运行

无需任何依赖（不需要 npm install）：

```bash
node build.mjs                 # 生成 index.html（多文件版）+ dist/inkboard-standalone.html（单文件版）
python3 -m http.server 8123    # 本地预览：http://localhost:8123
```

`build.mjs` 只做一件事：把 `src/template.html` 里的 `src/*.js` 与两个 CSS 内联成一个 HTML（单文件版），同时写一份保留外链的多文件版。

## 目录结构

```
SCHOOL_TOOLS_BOARD/
├─ build.mjs                 # 零依赖构建脚本
├─ manifest.json / sw.js     # PWA：可安装、可离线
├─ icons/icon.svg            # 矢量图标
├─ src/
│  ├─ template.html          # 页面骨架（工具、弹窗、课堂工具全在这里）
│  ├─ style.css              # 基准样式（1920×1080 设计基准）
│  ├─ style-ui-scale.css     # 大屏 / 4K 缩放覆盖层（--u）
│  ├─ 00-util.js             # 工具函数、IndexedDB、防抖
│  ├─ 10-geometry.js         # 笔迹几何、手绘识别、表达式解析
│  ├─ 20-model.js            # 文档模型、对象、命中测试、撤销栈
│  ├─ 30-render.js           # 画布分层、视口变换、页面渲染、FPS
│  ├─ 40-input.js            # Pointer Events、双指缩放、手掌防误触
│  ├─ 50-tools.js            # 9 个工具（笔、荧光笔、橡皮、图形、选择、文本、图片、激光、漫游）
│  ├─ 60-ui.js               # 界面装配：工具栏、取色、图形面板、页面栏
│  ├─ 65-ui-tools.js         # 课堂工具：聚光灯、遮罩、放大镜、计时、点名、导出
│  └─ 70-main.js             # 应用主逻辑：状态、撤销、持久化、PDF / 导出
└─ .github/workflows/pages.yml  # CI：构建并发布到 GitHub Pages
```

## 在课堂一体机上用

1. 用一体机浏览器打开在线版（或把 `inkboard-standalone.html` 拷到 U 盘里双击）；
2. 点右上角「全屏授课」进入沉浸模式（工具条变淡，顶栏自动隐藏）；
3. 想离线常驻：浏览器菜单「添加到主屏幕」即可安装为 PWA。

## 与希沃白板的差距（实话实说）

已覆盖：笔迹、荧光笔、橡皮、图形/函数、多页板书、课堂工具（计时/点名/聚光灯/遮罩/放大镜/板中板/PDF 讲评）、导出。

**尚未覆盖**：云账号与课件库、协同备课、学科工具库（尺规、化学器皿、物理电路）、微课录制、课堂活动（分组竞赛/抢答器）、截图提问、与教材资源打通。这些都需要后端与内容生态，不是前端单仓库能完成的。
